LEGAL ARCHITECTURE & COMPLIANCE

Privacy Policy

Effective Date: September 28, 2026

1. Information Processed

FutureEra processes solely the academic inputs submitted in the evaluation console (stream, declared interests, program duration, skills, and target career role), as well as optional peer profiles registered for community matchmaking. We do not sell user data to advertising brokers or commercial profilers.

2. Model Integration and Cloud Routing

Submitted parameters are transmitted to Google Gemini API endpoints solely to calculate career roadmaps, AI resilience scores, and technology audits. Synthesized roadmaps are persisted in a local high-performance SQLite database vault for offline retrieval.

3. Peer Matchmaking and Community Pods

Community profile data (username, display name, target role, and chosen interests) is shared within the peer discovery directory solely to enable mutual matching (≥ 2 shared interests) and 4-member squad formation. Passwords are cryptographically hashed using PBKDF2 HMAC SHA-256 with individual cryptographic salts.

4. Local Client Storage

Authentication tokens and client preferences are stored securely in browser local storage (localStorage) to maintain seamless cross-page session continuity.
