Privacy Policy

Effective Date: September 27, 2026

1. Information Processed

Future Era processes solely the academic inputs submitted in the evaluation console (stream, declared interests, program duration, skills, and target career role). We do not mandate user registration, names, phone numbers, or tracking identifiers.

2. Model Integration and Cloud Routing

Submitted parameters are transmitted to Google Gemini API endpoints solely to calculate career roadmaps, AI resilience scores, and technology audits. No user data is stored permanently for commercial profiling.

3. Local Client Storage

Custom API keys entered via the interface are stored exclusively in temporary browser session storage (sessionStorage) and are never persisted to external databases.
